🔧 Method 1: VS Code Extension (Installed)

The PlantUML extension is now installed! To view your diagram:

  1. Open lcat-architecture.puml in VS Code
  2. Press Alt + D (or Option (⌥) + D on Mac) to preview
  3. Or right-click the file → "Preview Diagram"
  4. Or use Command Palette (Ctrl+Shift+P) → "PlantUML: Preview Current Diagram"

🌐 Method 2: Online PlantUML Servers

Copy the content from lcat-architecture.puml and paste it into any of these online editors:

PlantUML Server PlantUML Editor PlantText

💻 Method 3: Command Line (If you have Java/PlantUML installed)

Generate PNG/SVG from command line:

java -jar plantuml.jar lcat-architecture.puml

🖼️ Method 4: Export from VS Code

Using the installed extension:

  1. Open the diagram preview in VS Code
  2. Right-click on the preview → "Export Diagram"
  3. Choose format: PNG, SVG, or PDF

📱 Method 5: PlantUML Mobile Apps

Copy the content and paste into:

  • iOS: "PlantUML Viewer" app
  • Android: "PlantUML Editor" app
💡 Pro Tip: The VS Code extension (Method 1) is the most convenient as it provides real-time preview, syntax highlighting, and export options all within your development environment.
